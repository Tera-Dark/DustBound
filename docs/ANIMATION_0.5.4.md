# 0.5.4 · 2D 动画与五挂点

## 本轮范围

总计 **1 个固定主炮 + 4 个副武器挂点**。01 主炮与 02 当前副武器启用；03–05 显示预留编号，在工坊注明不可装备。不是五把枪同时开火，也未增加装备/存档容量。

保留奶油色、粗轮廓、橙绿平面风格，未新增 3D 模型。原图集与资源保持不变；副武器采用可替换的程序化 2D 轮廓。既有射速、伤害、旅行时间、采矿收入和结算不变。

## 动画

- 武器：独立转向、解析弹簧后坐力与枪口闪光。机枪、电弧、轨道、喷火、迫击炮各自选择外形与弹道表现。
- 弹丸：服务器 shot 事件携带出生时间、挂点和轻量轨迹；即使在两次快照之间生成并命中，也能补出视觉轨迹。事件/快照按弹丸 ID 去重；视觉飞行不会因为下一包已没有该弹丸而提前消失。极晚事件最多补一个短暂飞行尾段。
- 矿工：出发、减速、放下钻头、钻探、收钻、返程、卸货，路径接缝连续；履带按位移滚动，钻头伸缩/振动，携货仍取服务器状态。
- 虫群：快照插值与有限外推，按移动距离驱动分相步态；不同敌人步幅/重量不同，加入出现、攻击、受击及退场姿态。
- 降低动态效果、独立闪光/震屏/血条/伤害数字开关仍有效。暂停/补给等待冻结运动；重开清空事件、弹丸与后坐力。

## 实现和预算

`Animation.lua` 为纯数学函数，`WeaponRig.lua` 负责挂点和外形，`Motion.lua` 负责呈现时间线及对象池。默认视觉缓冲 100ms，外推上限 200ms。不是新增网络往返，也不是修改战斗时间。

最多 80 个视觉弹丸、56 个其他效果、192 个等待呈现的事件。超限牺牲视觉事件，不影响服务器伤害或收益。腿部复杂姿态约 30Hz 更新，降低动态效果时 15Hz；根节点与弹道使用渲染帧更新。保留预热和对象复用，不承诺零分配。

## 后续增加武器

1. 在 `Catalog.weapons` 定义玩法数据（新增伤害/攻击行为仍需 Core 支持；本轮并非通用武器玩法编辑器）。
2. 给武器填写 `.visual`：`model`、`color={r,g,b}`、`muzzle`、`kick`、`projectile`、`length`、`width`、`arc`、`aimMin/aimMax`。
3. 外观可选已有 `ballistic/coil/rail/flame/mortar`；或 `sprite` 指向已有图集；或设置数字 `imageId` 和可选 `imageX/imageY/imageW/imageH/restRotation` 使用自行上传并获授权的 Roblox 图片。
4. 更复杂外形可在客户端调用 `WeaponRig.registerModel(name, function(block, colors, tint) ... end)`，然后在 visual.model 引用。请在首次 configure 前注册。
5. 五个挂点在 `Config.WeaponMounts`；当前服务器只下发 01/02 的启用装备。将来开放 03–05 还需要专门更新权威装备、存档、UI 和平衡，不能只把界面标记改成启用。

示例（外观，不增加新的攻击逻辑）：

```lua
D.weapons.machine.visual = {
 model="ballistic", color={135,226,185}, muzzle=40, kick=2,
 projectile="bullet", length=20, width=4, arc=0,
 aimMin=-20, aimMax=35,
}
```
