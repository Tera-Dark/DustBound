# 0.5.0 变更记录

日期：2026-09-16。范围：已批准计划中的 0.4.1 + 0.5 最小实现。

## 新增与修复

- 重写原生客户端布局；安全区四层 ScreenGui、宽横屏自适应、手机单卡投资与分支研究、横屏方向；零尺寸视口先等待，不错误报 UI 就绪。
- 独立三波教学；固定首通 180 合金 / 35 数据；重温零材料，教学不兑换矿料、不增加标准 bestWave、禁用无效精炼投资。
- `energy_2` ID 保持不变，电弧蓝图改为无前置/无波次限制，120 合金 / 20 数据；不额外增加科技节点。
- 首通追踪电弧；旧档已拥有时推荐其他尚未完成的早期节点。结算→研究→换装→标准远征接通。
- 经营台：威胁、实际投资变化、预算缺口、机器人货物/ETA/预计运回、上波输出摘要。
- 设置、研究目标、最后配装、2 个副武器预设纳入 schema 5；轻量动效、伤害数字、声音偏好实时消费。
- 请求 ID 去重、确认与超时同步；元数据上报不阻塞购买；等待业务请求时弹窗拦截重复操作。
- 云读取失败保护、明确访客、锁丢失冻结；保存失败保留稳定待写快照，重试后再保存新修改；同令牌重试丢失响应的锁获取。
- 一次性结算序号与教程标记；服务端诊断及可选平台事件。
- 基础音频模块与 13 个原创合成 WAV 上传包；默认仅兼容提示，不包含已授权可直接发布的 Roblox 音频 ID。
