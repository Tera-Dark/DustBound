# 0.5 Studio / 真实客户端验收单

状态：**待人工执行**。离线通过不等于以下条目已勾选。推荐先在独立测试体验验证，勿直接改生产档案。

## A. 打开与主循环

- [ ] 从文件打开 Dustbound-0.5.0.rbxlx；F5 / Play，而非 Run。启动页后出现主菜单。
- [ ] 无角色、未发布、云存档关闭时可开始；Output 无循环红错。
- [ ] 教学和标准两个入口存在，教学可跳过。默认显示本地试玩 Stop 不保存。
- [ ] 投资火炮 110，矿料扣费一次，24→31，按钮显示下一次价格和不足缺口。
- [ ] 战斗不采矿；清剿干净才弹补给；选择期间倒计时不走。
- [ ] 暂看投资→购买→回补给→接收，仍有完整 30 秒。
- [ ] 机器人出库/钻探/返航可看清；运回才涨矿料；第 3/10/12 波也有整备。
- [ ] 炮塔后坐、关节步态、弹丸命中时机、死亡反馈，没有明显卡死/飞离屏幕。

## B. 教学与长期成长

- [ ] 三波首通 180 合金 / 35 数据，不兑换剩余矿料，不提高标准 bestWave。
- [ ] 结算→研究电弧（120/20）→换装→再开标准远征；电弧实际参与战斗。
- [ ] 重温教学不再发材料；失利/放弃也不领首通；教学精炼不能购买。
- [ ] 旧档已有电弧时不要求重复研究。
- [ ] 研究前置/波次/四种资源检查正确，买一次只扣一次，效果下一局生效。
- [ ] 固定研究目标→查看缺口/来源→完成研究；工坊两个预设保存/装备正确。
- [ ] 三类图鉴分类、搜索、滚动、记录与已解锁条目正确。

## C. 暂停与布局

- [ ] 战斗/采矿暂停，时间/货物/Buff 停止；设置关闭仍暂停；继续不绕过补给选择。
- [ ] 返回主菜单先确认；取消保留远征，确认不领本局奖励。
- [ ] 战斗打开情报先暂停；关闭回暂停；采矿经营台预算更新但不凭空入账。
- [ ] Studio Device Emulator 至少 844×390、896×414、桌面 1440×810；再测有刘海/横屏系统栏的真实手机。
- [ ] 自动横屏、动态安全区域、旋转/窗口变化、顶部按钮、全屏遮罩无泄漏点击。
- [ ] 购买/接收/继续/关闭/列表节点实际触控大小与可读性可接受；特别检查安全区域较高的机型是否低于 44px。
- [ ] 分支列表/详情可滚动到底，底部操作不遮住重要内容，触摸滚动不误触购买。
- [ ] 轻量动效、伤害数字、音量切换；真实手机帧率、内存和温度记录，不以离线视频帧率代替。

- [ ] 备份 schema 4 样例迁移，材料/科技无损、旧加成不重复。
