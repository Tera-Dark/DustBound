# 0.5 事件与分析边界

`C.EnableAnalytics = false` 是默认值。服务端仍有本地诊断计数与最多 48 条最近事件，但不会调用外部分析端点；离开会话后本地历史不持久保存。

开关打开后，仅已发布、非 Studio 的服务端尝试 `AnalyticsService:LogCustomEvent`。没有将客户端任意字符串透传为自定义事件，没有自建第三方收集服务器。

## 事件

- 首次 UI 就绪、远征开始/再次开始、首次投资、波次清理、接收补给、首次机器人运回。
- 教学首通、远征结束、研究完成、研究目标、打开研究/图鉴/设置。
- 暂停/继续、放弃、保存失败、断线。客户端错误请看启动页/Output；`client_error` 当前仅预留白名单，未接通平台上报。
- combat / clearing / mining / supply / pause 五种时长；有效游戏时间不含后两种。

限定字段：CustomField01 = 版本；02 = 模式；03 = touch / keyboard / unknown（服务端也接受 gamepad，当前客户端尚未独立识别手柄）。字段不包括用户输入的搜索文本、自由错误堆栈或自己构造的个人资料。平台自身处理的数据仍受平台规则约束。

`sent` 只计 **pcall 未报错的 API 调用**，不证明后台收到了，也不证明报表已经可查询。请在独立已发布体验中手动走一遍首次路线，核验事件名、重复次数、模式、数值单位和接收情况，再用于产品判断。

## 本轮没有宣称的结果

没有真实首局流失率、D1/D7 留存、移动设备占比或收益数据，也没有据此保证推荐量。当前数值 pilot 不能代替真人首次体验。
