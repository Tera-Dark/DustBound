## 覆盖了什么

- 未发布本地启动、无服务器独立启动页、图像失败兼容显示、桌面/紧凑 UI、零尺寸视口等待和恢复。
- 帧/阶段推进、战斗不采矿、清剿、完整 30 秒整备、在途货物、暂停/补给计时、真实飞行弹丸与武器规则。
- 48 节点条件/原子扣费、图鉴搜索、滚动位置、解锁验证、设置、预设、目标。
- 教学三次整备、一次固定材料、重复教学零材料、教学精炼禁用、已拥有电弧的旧档目标处理。
- 桌面与手机：结算→研究→电弧装备→标准远征；补给暂看投资不解冻计时。
- 请求 ID 去重、等待层、约 3 秒超时重取状态、2 个玩家独立会话。
- 云构造/读取失败保护、明确访客、损坏外层/未来版本拦截、锁丢失、保存失败后的新修订、回调重放、提交成功但响应丢失后的重试。
- 音量与 Sound 方法被实际 mock 调用；UI 就绪/首运回事件唯一性、分析本地计数/平台可选路径。
- Roblox API 反射名称、基本属性/枚举约束；**不是完整引擎类型/行为模拟**。

从实际 Lua GUI 转译后检查了桌面与手机界面：手机改为利用横屏安全区域宽度；移开战斗文字与基地重叠；经营台把建议和数值变化提前，结算页顶部常驻存档状态；手机科技改分支列表/详情，补给保留三张卡与底部操作。

PNG 分别为桌面菜单/战斗/研究/结果，手机菜单/战斗/采矿/研究/补给/经营/设置/结果。视频重新生成，不沿用 0.4 证据。部分场景为控制布局的示例状态，不是完整玩家录像。字体、滚动条、缩放与真实 Roblox 可能不同。

## 还没有验证的内容

1. **不能运行 Roblox Studio / Player**：无法证明此版原生 UI、复制时序、资产下载或设备输入全部正确。
2. DataStore mock 不代表真实并发、预算、抢锁、重连、网络失败、关服时限；永久失败无法保证保存。
3. 手机真实 CoreUISafeInsets、刘海/系统栏、触控尺寸、字体回退、滚动手感、帧率/内存/温升待测。未保证所有尺寸 44px 命中区域。
4. EditableImage 和上传图集/声音审核、权限、可听性待测。默认仅兼容提示音，完整 WAV 需自行上传 ID。
5. Analytics API 调用成功不代表后台接收；没有真实留存、经济长期曲线、合作或商业化数据。
6. 无断线续局、真实合作、竖屏专用体验、字体大小设置；未进行长期 48 节点经济平衡或低端性能验收。
