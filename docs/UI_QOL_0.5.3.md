# DUSTBOUND 0.5.3 · UI 布局与 QoL

基于 0.5.2 的 2D 版本。目标是减少寻找入口、阅读长段文字和误操作的成本，而不是换掉游戏的基础风格。

## 直接体验

- Roblox Studio 打开 **Dustbound-0.5.3.rbxlx**，按 **F5 / Play**。
- 主菜单左侧进入「设置」，查看 **常用 / 声音 / 显示 / 高级** 四组。
- 桌面战斗顶栏新增设置入口：先请求暂停，再打开设置；关闭设置仍需手动继续。
- F6 悬浮性能诊断继续保留，高级页也可开关。

另附 `DustBound-UI-0.5.3.html`，可以切换查看布局图。**它是实际 Lua UI 经 mock 转译的离线排版预览，不是网页游戏，也不是 Roblox Studio 实机截图。** 浏览器字体和引擎最终排版可能不同。

## 保留与改变

**保留：**荒星卡通、原图集与基地造型、奶油色面板、深色轮廓、橙色主要操作、薄荷绿状态；不增加 Roblox 风格的 3D 模型，不替换美术资源。

**改变：**采用常见交互约定：左侧功能导航、醒目的主要开始按钮、货币置顶、固定战斗状态栏、底部投资区域、分组设置、开关文字状态和明确返回路径。这些是设计选择，**不是已经验证“绝大多数 Roblox 玩家偏好”的统计结论**；尚待真实玩家和手机用户测试。

### 主菜单

- 左侧集中研究、工坊、图鉴、设置和手册，减少入口散落。
- 标准远征为稳定的橙色主操作；教学保留明显的独立入口，首次推荐使用绿色强调。
- 钱包放在右上，研究目标放在基地展示下方。
- 原基地美术成为独立展示区，不再和开始按钮混排。
- 本地 / 访客未保存状态继续明确显示，不能用精简 UI 掩盖存档限制。

### 战斗 HUD

- 品牌、波次、基地耐久、矿料、暂停与桌面设置集中在顶部状态栏。
- 阶段进度、情报入口、战术提示形成相邻区域。
- 战术建议增加浅底，提高地形上的文字可读性。
- 底部投资保留原有分类与手机单卡分页；加入编号、桌面快捷键标记和选中下划线。
- 不只靠颜色表达选中状态：设置开关有「✓ 开启 / — 关闭」，补给有勾选标记，分类有下划线。
- 缺钱、满级等禁用操作使用弱化样式；普通按钮不再一律染成橙色。

### 设置

普通玩家先看到常用选项，不再一打开就是图像 API、云存档和帧时间诊断。每项采用“名称 + 简短解释 + 开关 / 调节按钮”，长页可滚动，完成与恢复默认按钮固定在底部。

## 实际接入的设置

共 **14 项偏好**：沿用 4 项，新增 10 项。

| 类别 | 选项 | 默认 | 行为 |
|---|---|---|---|
| 常用 | 战术建议 | 开 | 关闭普通建议；教学、低耐久和存档警告仍保留 |
| 常用 | 简写资源数字 | 关 | 大额余额用 K / M；购买价格和结算仍显示精确数值 |
| 常用 | 切出窗口自动暂停 | 关 | 失焦时向服务端请求暂停；切回后绝不自动恢复战斗 |
| 常用 | 付费重抽确认 | 开 | 免费重抽直接执行；消耗矿料前确认，显示费用和余额 |
| 常用 | 游戏快捷键 | 开 | 控制 P、1/2/3 与退格返回；鼠标按钮和 F6 诊断不受影响 |
| 声音 | 全部静音 | 关 | 停止现有提示音并静音音乐，不清空音量数值 |
| 声音 | 后台静音 | 开 | 切出窗口静音，切回恢复；不要求同时开启自动暂停 |
| 声音 | 音效音量 | 65% | 每次 ±10%，服务端限制在 0–100% |
| 声音 | 音乐音量 | 25% | 同上；没有配置音乐资源时不会凭空出现背景音乐 |
| 显示 | 轻量动效 | 关 | 保留上一版优化，降低复杂姿态更新 |
| 显示 | 伤害数字 | 开 | 独立控制伤害飘字；轻量动效不再强制覆盖这个选择 |
| 显示 | 受击震动 | 开 | 关闭基地受击抖动，不改变伤害判定 |
| 显示 | 闪光特效 | 开 | 关闭枪口、命中闪光与冲击光圈，保留弹道和必要攻击表现 |
| 显示 | 敌人血条 | 开 | 控制敌方头顶血条；基地耐久始终显示 |

这些显示设置不构成光敏安全认证，也不是完整的无障碍支持承诺。

## 其他 QoL

- **恢复默认有二次确认**：只重置偏好，不动资源、科技、配装或教程进度；也不会解除暂停。
- **付费重抽不会误当 Robux 消费**：明确标注只消耗本局矿料。报价或补给令牌变化后，旧确认界面不能继续使用；服务端原有价格与令牌校验保持有效。
- **返回与关闭分开**：「‹ 返回」或退格回上页；「×」退出这一组页面，暂停时回到暂停菜单。恢复远征仍是显式操作。
- **暂停菜单音效正常播放**：不再每次音频更新都停止声音，避免试听音被不断截断。
- **窗口失焦处理**：自动暂停开启时优先在事件中发请求；若另一个请求尚未确认，则在后续帧继续尝试。断网或调度延迟时不能保证立即暂停。
- **保留 Roblox 系统入口**：不再把所有 CoreGui 一起关闭，保留平台聊天和玩家列表；实际可用性仍受 Roblox 设置与权限限制。
- 不增加自动购买、自动领取、跳波或自动继续，以免 QoL 选项偷偷替玩家做策略决定。

## 存档与兼容

- 保持 `Dustbound2D_Profile_v1` 和 schema 5。
- 新偏好是可选字段：旧档自动补默认值，已有音量、轻量动效和伤害数字选择保留。
- 服务端逐项白名单验证；布尔选项拒绝数字 / 字符串，音量拒绝非有限值。
- 开启并成功连接云存档时，偏好随档案保存；默认本地模式和访客模式仅保留当前会话。UI 已按模式提示。
- 新旧版本混合运行时，旧服务器可能在清洗档案时丢弃它不认识的新偏好字段；发布新版本建议统一重启旧服。资源与科技字段未改变。

## 性能与验证

- **193 项 pytest 通过**，比 0.5.2 新增 32 项；旧测试随设置导航和 10% 音量步进更新，原有行为检查保留。
- **8,000 条原生 Luau 属性断言通过**。
- **17 个脚本编译通过**，6 个纯模块静态分析无诊断。
- 教学、标准十波和追加十二波的固定策略模拟通过，结算结果与上一版一致。
- 原位刷新、加载分帧、预热对象池、动画时钟与 F6 诊断保留。
- 同一十秒离线经营台样本仍为 **0 次对象销毁**；早期战斗样本仅创建 3 个实例。属性赋值略高于 0.5.2，这是新增状态与布局带来的开销；没有宣称本轮提高了实机 FPS。
- 重新生成 **15 张离线排版图**，覆盖桌面大厅、战斗、设置及手机横屏等。
- 美术资源和 `ArtData.lua` 与上一版逐字节一致。

原始记录位于 `docs/validation-0.5.3/`。

**未完成 Roblox Studio 真机、实际触屏、真实音频和线上云端验收，也未做受众偏好 A/B 测试。** 仍以横屏体验为主，未新增独立竖屏玩法布局、语言切换或完整手柄导航。

## 建议验收路线

1. 大厅查看钱包、研究目标、教学与标准远征入口。
2. 手机横屏进入设置，滚动常用 / 显示列表，检查手指点击区域与文字。
3. 开战后关闭震动和闪光，对比命中、弹道与血条是否符合预期。
4. 开启自动暂停，切出窗口再切回；确认没有自动恢复战斗。
5. 领取免费重抽，再尝试付费重抽：取消不扣钱，确认才扣矿料。
6. 工坊进入解锁研究，分别尝试返回与关闭。
7. 修改偏好后恢复默认；确认资源、科技、配装、暂停状态未变化。

构建：`python tools/build_place.py --rojo <rojo路径>`。

原仓库未推送修改。完整包仅含当前 2D 工程，不混入 3D 实验或旧版 Place。
