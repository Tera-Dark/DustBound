# 0.6.1 · Demo 候选版 / 科技树与 QoL 收尾

## 本轮修正

上版放射状布局和跨分支长连线未达到规整、紧凑的要求。本版取消该布局：

- 6 条科技分支按行排列，8 个阶段按列对齐；统一节点尺寸和间隔。
- 同分支的依赖只有节点边缘之间的短水平线，逻辑长度 48；不再从中心拉放射线，也不默认绘制跨分支长线。
- 跨分支条件没有删除：节点右上角用 ↗ 标记，选中后所需科技显示绿框，右侧列出真实前置，点击前置可定位。
- 全图用于观察路线，放大后显示节点名称与级别；保留平移、缩放、定位、全图复位。
- 研究数据、前置门槛、已拥有科技和效果未改变。

## QoL

1. 缩放、全图与定位按钮加大；新增「找可研究」，跳到当前可负担且满足前置的节点。没有可研究节点时按钮禁用。
2. 资源不足时显示具体缺口，而不只是「资源不足」。
3. 从大厅进入星球远征时，定位下一未完成节点；全通后定位最后节点。浏览航图期间仍可自由选择旧关。
4. 小屏图鉴详情插画由最大 236 降为 142 逻辑像素，减少为了看到名称/参数而额外滚动的距离；桌面保持大图。
5. 离线预览顶部对齐，移除原先纵向居中产生的大块上方空白，默认先展示科技全图。

原来的返回/关闭导航、付费重抽确认、设置、暂停、图片兼容降级均保留。没有新增武器位火力、星球、资源或数值机制。

## 使用

打开 `Dustbound-0.6.1.rbxlx`，Play/F5。完整 ZIP 包包含源码、资源和验证输出。`DustBound-0.6.1-preview.html` 为独立六页签离线预览，不是可玩游戏；预览中的游戏按钮不是 Roblox 输入控件。

存档仍为 schema 6，存储名不变；0.6.0 的关卡进度与科技可继续使用。云保存仍默认关闭；需要跨会话保存时，应在发布的测试体验中按原说明启用并验证。不要误把未启用云保存的本地测试当作持久存档。
