# DustBound 0.9 · FIRST CONTACT

2026-09-17｜第一轮玩法优化｜可试玩开发版，非正式发行验收

## 本轮实际完成

- **首关即可形成打法**：第 1 波清场免费选机枪、电弧或磁轨；其后第 4/8/12 波可继续获得副武器，最多四个副位。遗物改为第 2/5/9/13/17 波。最终波直接结算，不出现无意义补给与等待。
- **采矿整备可主动结束**：前两次 18 秒，之后 14 秒。面板显示已采在途矿量、按当前配置继续采矿的预计收益、返航时间。提前收队放弃未完成钻探，已采货物返航入库；计时自然结束同样安全回收。矿运保险与相应科技免除返航等待。
- **明确的敌人编队**：着陆警戒、重甲护送、空地夹击、疾行突围。增加可辨识的疾行虫，区分左右地面与上方空袭。队列达到敌人上限时延后生成，不丢弃尚未到场的敌人。
- **主炮目标选择**：近身、空中、重甲优先。机枪优先快敌，磁轨瞄准护甲目标并沿射线穿透，电弧寻找密集队列，迫击炮选择高生命目标。切换可能放过其他威胁，不保证总是更优。
- **投资显示真实收益**：由服务器返回当前→下一档数值及禁用原因。满耐久维修禁用，暂停、免费选择、回收中不能投资。修复旧面板“满血也可点击维修”的误导。
- **结算解释结果**：实际有效武器伤害、最高承伤波次、主要伤害来源与针对性建议。浏览器与原生 UI 均接入。
- 保持 24 个任务与原有存档格式；未扩大关卡或更改永久钱包结构。未推送 Git、未发布 Roblox。

**提前收队的取舍**：同一均衡策略，每次首次入库后立即收队，完成 24 关的模拟时间为 130.7 分钟；总采矿从 135,330 降至 38,454，累计承伤从约 2,894 增至 3,965。减少等待并非免费获得同等强度。

初版调参曾让均衡策略止步第 19 关，已保留数据 `iteration09/results/balance-first-tuning.json`。随后降低后程密度与生命曲线；没有删除失败实验或覆盖原 0.8 评审证据。

## 验证与边界

- 109 项重点测试通过：早期补给、暂停、重放与过期令牌、矿量预测、运输守恒、保险、目标优先、队列上限、维修收益、原生 UI 控件与旧回归。
- 全套 **221 通过 / 128 失败**；原评审为 195 通过 / 129 失败。新增 25 项测试，并迁移明确变化的波次/时间/生成队列测试夹具；失败 ID 无新增，解决一项“后期不研究没有明显难度”的旧断言。其余历史失败仍需逐项整理，不统称为过时。
- Luau 0.738 编译通过；原生语言 CLI 审计 236,329 条断言通过。断言数减少来自更短的采矿窗口，不能用来证明覆盖扩大。
- 实际 Chromium + Lua 服务端首关闭环通过：投资、首把电弧、主炮目标切换、收队确认、遗物、暂停/继续、空袭、结算、研究、解锁下一关。首关约 100 秒有效模拟时间；整段约 104 秒墙钟时间。无注资、无时间加速、无未捕获 JS 错误。
- 390px 浏览器战斗和投资面板无横向溢出；竖屏战场仍偏小，不等于触屏手感已验收。
- 原生 UI 在 mock API 宿主中验证，不是 Roblox Studio。未验证真实设备帧率、游戏手柄、Roblox 声音、云档和多人长期稳定性。
- 三星球和中枢战仍没有独立机制；本轮解决的是基础战斗循环，不声称已完成行星差异化。

## 使用与复验

主文件：`Dustbound-0.9.0-FIRST-CONTACT.rbxlx`，用 Roblox Studio 打开并 Play。默认云存档仍关闭。

浏览器：`pip install -r tools/preview-requirements.txt`，然后 `python preview/server.py --port 8080`。仅内存会话，不写 Roblox 云档。

```
python -m pytest tests/test_first_contact_09.py tests/test_frontier_08.py tests/test_integration_07.py tests/test_audit_07.py -q
python iteration09/run_balance.py
python iteration09/browser_check.py  # 先运行预览服务，并安装 Playwright Chromium
luau tests/audit_native.luau
python tools/build_place.py --rojo /path/to/rojo
```
