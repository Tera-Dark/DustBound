# 0.6.0 · 星球远征、科技大图与插画图鉴

## 入口与范围

Studio 打开 `Dustbound-0.6.0.rbxlx`，使用 Play / F5。大厅主按钮进入「星球远征 · 24 关」。三波教学和原来的十波标准远征仍保留在下方，标准模式的数值与结算未改。

- **3 星球 × 8 节点**：赤砂（3–6 波）、青岚（6–9 波）、紫霜（9–12 波）。按顺序首通解锁下一节点，可以回刷已完成节点。
- 本轮采用同一套 2D 战斗场地结构，星球有不同插画、环境色调和数值曲线；**不是三套全新地形，也没有新增怪物战斗种类**。每个星球第八节点在终波追加精英出场规则。
- 五挂点规则不变：主炮 + 一件副武器启用，另三个预留；0.5.4 动画、0.5.3 舒适度设置保留。

## 科技中心

48 个现有研究节点改为六分支大图，绘制全部前置依赖，包括跨分支依赖。节点 ID、已拥有科技和效果保持兼容，本轮不是增加 48 项新科技。

- 默认显示全图概览；「+ / −」缩放，「全图」复位，「定位」放大并定位当前研究。
- 桌面拖动空白处平移；触屏使用原生双轴滚动，缩放使用按钮。未实现双指捏合缩放。
- 概览用于看路线，节点文字在放大后显示；右侧查看费用、效果、前置与波次门槛，底部追踪或研究。
- 已完成、可研究、未解锁有不同颜色。图形布局通过节点矩形不相交测试；真实触控命中与设备性能仍需 Studio/真机检查。

## 插画与素材

新增 16 个 AI 生成的 2D 插画：6 武器、6 怪物、3 星球、1 补给箱。用于图鉴列表缩略图、图鉴详情、工坊、航图和研究节点。补给仍使用统一箱体插画，不是每份补给各一套新原画。

- 原始高清图集：`assets/expedition-gallery.png`。
- 16 个可单独编辑的裁切图：`assets/gallery/*.png`。
- 运行时图集：`assets/expedition-gallery-runtime.png`，512×512、128 色；原始插画质量高于运行时缩略图。
- `tools/build_gallery.py` 生成内嵌 `GalleryData.lua` 与单图资源。首次打开相关界面时分条解码为独立约 1 MiB RGBA 图像，共用一次；不改变旧战斗图集解码。
- 图像 API 不可用时，使用程序化 GUI 武器/虫体/星球轮廓作为兼容降级，不会保持空白。降级版本不等同于高清插画。
- 这些是静态插画，不是新增的逐帧战斗动画。旧战斗美术与动画骨架沿用。

## 难度与资源设计

节点波数为：

```
赤砂：3, 3, 4, 4, 5, 5, 6, 6
青岚：6, 6, 7, 7, 8, 8, 9, 9
紫霜：9, 9,10,10,11,11,12,12
```

节点编号 n 从 1 到 24。怪物耐久在原来的种类/波次基础上乘 `0.8 + 0.035n + 0.012n²`；攻击乘 `0.8 + 0.024n`；生成密度乘 `0.88 + 0.01n`。出发额外矿料为 `6(n−1)`。这些倍率不会应用于旧标准模式或教学。

曲线没有星球切换时的额外突增。后段耐久增长更明显，用于让沿途研究、配装和局内投入真正有价值，而不是只把关卡时间拉长。完整节点表见 `campaign-balance.csv`。

### 奖励

- 合金、数据、晶体：**首通为基准 180%，重打为基准 80%**，再计对应永久研究加成。不是重打给首通奖励的 80%。
- 基准合金 `130+16n`，基准数据 `20+3n`；第五节点起有晶体。
- 核心：星球中枢或紫霜节点胜利时固定 1 个。重复胜利仍有核心；失败不发核心。
- 精炼继续有效：每级使节点研究数据增加 20% 基础值。航图显示的是不含本局精炼的预计值，局内预览考虑精炼。
- 星球节点的剩余矿料**不直接换合金**，用于本局投入。标准模式仍保留原来的结余兑换规则。界面已区分说明。
- 失败：至少击杀 3 个敌人才有奖励；按已推进波次/击杀进度保留部分基准材料，基础系数 45%，相关保险研究继续生效。不是每次失败固定领取首通奖励的 45%。
- 无体力/出发资源消耗，无即时投降奖励；失败不回退已完成节点，不移除科技或配装。防止卡关后因无法支付出发费用而形成死局。

### 建议节奏

首星球熟悉钻机、主炮与整备；中期通过电弧/穿透等路线处理混合虫群；后期需要更完整的火力与防御成长。卡关可调整研究、配装或少量回刷，不设置强制刷关次数。

## 存档与权威校验

存档 schema 升为 **6**，新增 `campaignCleared`（0–24）。旧版资源、科技、配装、偏好保留，旧档从星球第一节点开始；原最佳波次不直接转换为星球首通。

服务器检查节点范围、整数、解锁条件与当前阶段；奖励和首通状态由服务器结算，既有 runSerial/settledSerial 防重复结算。无断线续局；已保存的长期进度与正在打的关卡是两回事。

**部署请完整更新客户端和服务器，关闭旧版本服务器后再开放。** 新档不应被旧脚本写回；未来版本存档的拒绝读取保护仍在。云保存默认关闭，需按原有说明发布并启用；本轮只做了 mock 云档读写验证，不是真实 DataStore 测试。

## 验证与边界

- 236 项 pytest 全通过；新增 31 项覆盖关卡锁定/畸形参数、首通与重打、失败与零收益投降、精炼、存档迁移、24 关连推、后期无研究对照、图集复用与降级、RGBA 一致性、科技图连线/拖动/复位/节点不相交。
- 8000 项原生 Luau 属性断言；22 个源脚本编译；6 个纯模块静态分析无输出。
- 普通数值自动策略从空档连续通过 24 节点，没有注入资源、没有额外回刷，沿途购买 35 项研究；模拟活动时间约 **191.2 分钟**（不含玩家思考、读图、补给选择时间）。最终节点 12 波、836.2 秒、剩余耐久 1451。
- 对照测试仅为访问最终关而设置解锁标志，不给资源/科技/属性：无永久研究的最终节点在第 5 波失败，得到 87 合金、15 数据、1 晶体、0 核心。这证明研究具有作用，**不证明所有玩家都能少量升级后通关**。
- 三条旧模式试跑与 0.5.4 一致：教学 179.7 秒 / 33 击杀；标准 607.9 秒 / 159 击杀；延长 728.3 秒 / 223 击杀。
- 22 张实际 Lua GUI 转换的离线布局图，以及单文件六页签预览；不是 Studio 截图或实机录像。
- 600 mock 帧的标准战斗创建 3、销毁 0、属性赋值 31779 次。仅为操作计数，不是 FPS。首次科技图构建与额外插画会增加菜单资源消耗。

仍需在 Roblox Studio / 真机验证：图片权限与内存预算、异步解码、拖动/触屏命中、低端设备帧率、真实网络/存档，以及真人的卡点与重刷体验。本版是已通过离线回归的首轮内容和平衡实现，不是完成真人调优的最终数值。
