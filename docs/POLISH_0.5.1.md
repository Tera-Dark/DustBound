# DUSTBOUND 0.5.1 · 2D 体验打磨

基于原仓库 0.5.0（`921fcf5`），回到原生 Roblox 2D 路线。本次是现有循环的一轮完整打磨，不是换一套美术，也没有追加新敌人、地图、商业化或材料体系。

## 开始体验

用 Roblox Studio 打开 **Dustbound-0.5.1.rbxlx**，按 **F5 / Play**。

- 新玩家先玩「3 波教学」。
- 主菜单新增「? 指挥官手册」。
- 已熟悉玩法可直接进入标准远征。
- Rojo 开发使用 `default.project.json`，不再使用之前的 `presentation.project.json`。

本交付包只包含 2D 工程。工作区中的旧 3D 文件没有被强行删除，但不被当前工程引用，也不在这次压缩包中。

## 改进清单

### 1. 教学与提示

- 增加六节可滚动手册：自动战斗、投资、补给与入库、能源与增益、撤离与进度、操作与舒适度。
- 教学明确“推荐”而非强制购买某项强化，避免玩家买了其他升级后怀疑操作错误。
- 手机采矿阶段不再用普通货物提示覆盖教学的后续目标。
- 教学失败后提供「重试三波教学」，不会把玩家直接推进标准十波。

### 2. 补给选择

- 根据当前状态默认选中一份建议补给；仍可自由改选。
- 维修显示**实际可恢复耐久**，满耐久明确提示无收益，不再默认诱导领取空维修。
- 显示研究修正后的持续时间、维修效果和护盾减伤。
- 最终整备提示战斗增益可能无用；第十波说明只有继续追加波次才会用到。
- 已有同类增益时，解释刷新时长而非叠加倍率。
- 长说明在卡片内滚动，减少小屏溢出。

建议是只读启发式规则，不是自动消费或“最优解”承诺；领什么仍由玩家决定。

### 3. 投资与经营

- 推荐投资避开满级、满血维修等无效目标，并显示资源缺口。
- 全部关键升级已满时，提示保留矿料，不催促无意义消费。
- 最终整备提醒考虑精炼、剩余返航时间和保留矿料的价值。
- 桌面投资卡展示当前等级 / 上限；暂停或教学禁用等情况显示具体原因。
- 小屏投资描述与购买按钮分区，避免文字重叠。
- 桌面能源按钮高亮当前服务端确认的分配状态。
- 战斗中打开经营台显示当前波威胁和机器人待命说明，不再误导为正在采矿。
- 工坊可切换并使用现有的两个配装预设槽；未改变存档字段。

### 4. 战况反馈

- 战斗生成 / 整备阶段加入进度条；清剿仍显示剩余敌人数，不把生成结束当成清场。
- 显示临时增益剩余时间；暂停、补给选择和非对应阶段标为「待机」。
- 低于 30% 耐久触发告急提示；恢复到 45% 后才重新允许触发，避免临界点反复提醒。
- 警报音从“每次受击提示”改为低耐久事件，并限频。
- 整备最后 5 秒提醒检查维修 / 能源；最终波改为结算 / 撤离提示。
- 小屏增益信息使用浅色底，提高在地形背景上的可读性。

### 5. 结算与复盘

- 新增本局资金记录：击杀回收、矿料空投、消费、未返航货物。
- “消费”包含局内升级与付费重抽；未返航货物不计入收入。
- 增加战斗、采矿、选择补给、暂停的时间拆分。
- 说明剩余矿料与研究数据的结算来源；失败明确显示保留比例。
- 按教学首通、教学练习、输出不足、采矿分配失守等情况给出下一步提示。
- 十波决策显示当前耐久，并提醒继续深入的失败风险。
- 记录本局各波摘要供后续展示使用；本版界面仍展示已有的上波摘要，不另加一套战报页。

### 6. 稳定性

- 修复零耐久可能先被自动维修恢复、从而绕过失败结算的边界。
- 修复增压伤害致死当帧仍可能进入整备的边界。
- 实际承伤不再把超出剩余耐久的过量伤害全部计入统计。
- 服务端拒绝请求时优先返回具体原因；不复用不相关的旧提示。
- 请求超时显示“尚未确认 / 已同步”的反馈，不自动重发购买。
- 弹窗缓存加入局次、阶段、暂停与补给相关状态，避免重复远征或投资后残留旧内容。

## 不变的部分

- 沿用原 2D 图集、背景、基地和机器人美术；未宣称整套视觉重制。
- 不调整敌人基础参数、波次长度、升级价格、教学奖励或结算公式。
- 保留原 `Dustbound2D_Profile_v1`、schema 5、科技 ID、既有资源和存档保护逻辑。
- 默认云存档与分析开关仍关闭；云档接入请在已发布测试体验验证后启用。
- 本局新增统计只属于运行状态 / 结果，不写入长期档案。
- 仍以横屏体验为主；没有独立竖屏玩法布局、断线续局或真正合作模式。

## 建议你优先体验的路线

1. 主菜单打开手册，再进入教学，购买任一投资。
2. 第一波清场：检查维修显示 0、建议为钻机加速；接收后查看增益倒计时。
3. 在整备中切换能源，查看产量估算与高亮变化。
4. 教学结算：滚动查看资金记录、复盘，研究电弧并装备。
5. 工坊切到预设槽 2，保存；换回机枪，再应用槽 2。
6. 开标准远征，分别检查战斗经营台、低耐久提醒与最终撤离决策。
7. Studio 设备模拟器检查窄横屏；真实手机检查长补给说明的滚动和选择手感。

## 开发命令

```sh
python -m pip install -r tests/requirements.txt
python tools/build_place.py --rojo <rojo可执行文件路径>
python -m pytest tests -q
luau tests/native.luau
python tests/pilot.py
```

原仓库未被推送修改；源码包可解压到单独目录对比，确认后再合并。
