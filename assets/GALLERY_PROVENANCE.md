# Expedition illustration provenance

`expedition-gallery.png` was AI-generated for this update on 2026-09-16, following the requested cream/orange/mint, heavy-outline flat 2D game direction. It is not a photograph, not hand-drawn commissioned art, and not extracted from the user's reference screenshot. That screenshot guided the technology-tree interaction/layout discussion only.

The 16 individual `gallery/*.png` tiles are crops of this generated sheet. The 512×512 runtime PNG and GalleryData.lua are deterministic palette/downsample derivatives produced by `tools/build_gallery.py`. This atlas supplies static menu/encyclopedia illustrations, not replacement frame-by-frame battle animation. The original battle atlas is unchanged.

EditableImage support and memory depend on Roblox/device configuration; native procedural silhouettes remain as fallback. No external image hosting or uploaded asset IDs are required for this gallery path.
